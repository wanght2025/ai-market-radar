## 数据缺口：哪些需要补，哪些需要解释

| 项目 | 当前原因／边界 | 对试用版的要求 |
|---|---|---|
| 前一日全市场快照 | 当前只有一个正式发布日期，不能计算同口径全市场成交额和上涨家数环比。指数本身已有连续历史，不应泛称“所有历史缺失”。 | 后续正常采集逐日积累；无基线时只展示当日事实，不编造环比。 |
| 深市融资 | 上游空响应或连接失败；上交所数据可用，但不能冒充沪深合计。 | 显示日期、覆盖范围、失败原因与重试状态；缺失不填零。 |
| 行业资金映射 | 东方财富128类资金与申万31行业的分类口径不同；未完成成员映射，不是128类未采集。 | 分开使用、解释归因边界；不能把供应商分类净额直接贴到申万行业。 |
| ETF份额 | 已取得10项日间比较；份额变化仍不等于现金流入或特定机构买入。 | 现有数据可使用，禁止扩大含义。 |
| 跨境／国家队身份 | 部分渠道尚未接入；具名机构每日净额也不必然存在公开可核实数据。 | 可以作为试用范围限制，不要求为了“填满”而制造数据。 |
| 个股完整风险 | 公告目前为有限样本，`full_risk_verified` 为false；空公告样本不等于无风险。 | 不能宣称已完成全部风险排查。完整全文排险可以分期，但“通过有限研究门槛”与“完整风险核验”必须分清。 |

这些缺口并非都要成为发行阻塞。关键是核心评分链路可工作、缺口影响明确、局部证据不会被用作不支持的结论。

## 试用期间继续做

- 连续3–5个真实交易日观察采集、盘后研究、盘前更新、失败保留和补采。当前只有一份正式日期、真实前瞻0天，不能宣称连续运行或预测效果已验证。
- 每个到期的1／3／5交易日自动记录原预测及后续事实，先检查是否正确保存和复核；样本不足不展示命中率或收益能力。较长样本积累属于持续验证，不必为了小范围试用等待20天。
- 把上游故障与口径限制分开统计，优先修复可恢复渠道；没有同口径公开资料时明确范围。
- 持续抽查AI内容与使用费用。请求次数不封顶不等于费用不受预算约束；保留已有token预算和失败请求记录。
- 2026年历之外的调度继续按未知年度处理；取得官方2027安排后再扩展，不能猜测交易日。
