## 用户路径

今日判断先看市场广度、指数与环境评分，再看AI短结论、机会偏向、确认条件与最大风险。低环境分与反转观察分别表达，缺少估值和连续情绪历史时不称低估、极端恐慌或底部确认。

首页机会表进入板块详情；先展示量价与成员事实，再展示主要推论、替代解释、启动/盘整/转弱情景。确认条件与反证默认可见，证据可以直接打开。股票详情保留参与前提、观察参考、风险与失效；MA5/MA20不生成买入价。

自选可加入、删除、保存，并显示已存行情、板块机会与判断日期。历史区分原发布预测、晚生成再解读和后续条件核验；1/3/5个交易日窗口没有数据时显示待核验。

## 已接入能力

- 独立版本 `opportunity-v1`：潜在启动、反转观察、趋势跟随、衰退风险，保留原行业规则状态。
- 程序扫描31个申万行业，AI按机会类型覆盖最多8个行业。175个概念仅展示已有成员事实，供应商128行业资金独立展示，不映射为申万行业流入。
- 下一次完整更新从机会行业选择最多6只候选，每行业最多2只，并沿用原流动性和异常名称过滤。历史旧候选不重写；不同候选版本不直接计算新增/退出。
- 固定信号日失效参考，确认条件完整匹配程序ID。衰退风险按转弱持续确认、走强缓解失效，避免把反弹算成衰退预测成功。
- 概念和自选归属使用正式报告绑定的成员版本。后续缺失不填0；保留过去确认日期，同时把当前无法核验状态显示为缺失。
- 新诊断属于研究观察规则，当前没有足够前瞻样本证明预测准确性。
