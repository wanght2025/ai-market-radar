## 1. 产品链路

市场支持度评分与情绪图示 → 今日重点机会 → 板块异常及AI解释 → 个股研究与参与条件 → 自选跟踪 → 次日/3日/5日复核。

沿用五个页面。机会雷达放进“今日判断”和“板块机会”，无需增加聊天页、独立导航或新的前端框架。

首页先回答：当前市场支持程度、偏向哪类机会、重点看哪些方向、是否确认、最大的风险。具体事实、计算定义和模型引用可以展开核对。

## 2. 当前架构中需要补的连接

- decision.py已有五维评分、31个行业规则、个股条件与结构化AI；技术分主要是三指数在MA20上方的比例，资金分是完整供应商行业资金净额为正的比例，情绪分是上涨广度和等权涨跌组合。它们不是估值、机构身份或极端恐慌指标。
- history.py现有shortlist从领先5行业取流动性股票，合并最多6只，容易遗漏尚未上涨的板块。现在先选股票、再收集行业和股票历史；要做潜在机会选股，需要调整次序。
- decision.interpret当前优先规则信号，再补领先行业，最多8行业。应改为覆盖不同机会类型，再按证据质量选取，仍保留8行业上限。
- predictions.py已冻结原判断并在第1、3、5交易日检查行情结果，可扩展解释性复核；不必另建回测系统。
- 当前只有2026-09-30一份正式发布。比较缺失和历史再解读必须继续明确标记。

## 3. 评分与机会类型

保留原五维公式、权重和总分，首页名称改为“市场支持度”，解释其反映现有趋势、资金代理、事件样本与市场广度对参与的支持程度。总分不是所有策略的机会评分，也不是上涨概率。

每项显示“分数 + 人话 + 为什么”：例如技术0分解释为“三个核心指数均在20日均线下方”，资金32分解释为“约32%的已覆盖供应商行业资金净额为正”。不能让用户把0分理解成市场毫无机会，把32分理解成资金总量。

在总分旁加入两条独立诊断：“趋势跟随条件”和“反转观察条件”。首版用“满足几项/等待哪些条件”表达，避免未经校准的第二套0–100分。缺失项单列未知，不作为不满足，也不放大已知项比例。环境低分仍可出现反转观察线索，原大盘行动标签保持原样，任何分歧由AI解释。

反转首版只研究价格止跌和参与改善。不把跌幅、低情绪或MA20距离称为低估；没有估值和连续情绪历史时，“估值便宜”“极端恐慌”“恐慌后改善”均显示证据不足。

## 4. 研究范围

| 范围 | 本轮用途 | 边界 |
|---|---|---|
| 31申万行业 | 全量机会扫描、已有连续量价比较、板块情景 | 主研究范围，规则和来源明确 |
| 128供应商行业资金 | 原分类下的资金事实与市场资金解释 | 无核验映射不拼接申万行业；单日记录不称连续流入 |
| 175已采集概念 | 若已有成员与当日行情齐备，计算当日涨跌、相对强弱、广度和候选成员；标注保存成员口径 | 不增加采集请求；没有概念连续历史时只作当日线索，不给连续启动或时长判断 |
| 股票 | 从机会板块产生最多6只研究候选，沿用原历史/资料/公告适配器 | 换选择逻辑，不扩大日常深查数量；公告有限样本不包装成完整核验 |

行业、供应商资金分类和概念覆盖数量不能相加称为“扫描334个独立板块”；概念重叠股票去重，不能重复计成相互独立的支持证据。全量扫描是程序的范围，AI深读范围单独标记。

## 5. 新增机会诊断（独立版本，不改原标签）

建议增加一个小型opportunities.py模块，读取已有指标与历史，写入analysis.opportunities。保留decision原结构和标签，新增规则版本opportunity-v1，并将版本和条件冻结。

| 类型 | 首版条件 | 展示与限制 |
|---|---|---|
| 潜在启动 | 沿用原启动候选条件：相对强弱>0、广度≥50%、收盘>MA5、5日收益在−2%至3%、距MA20不超过2.5%、成交额/前5日均额≥1.2 | 解释为近期涨幅有限而成交关注增强；未满足时可展示具体缺口，不能称已启动 |
| 趋势跟随 | 沿用原强势延续观察条件 | 解释趋势和广度一致；过热/入场位置独立提示 |
| 反转观察 | 新研究条件：5日收益<0、行业指数当日上涨、收盘>MA5、同日行业相对强弱>0、广度≥55% | 仅表示近期走弱后出现改善；不能称底部确认或价值低估 |
| 衰退风险 | 沿用原衰退预警条件 | 展示近期上涨后相对表现或广度转弱 |

“行业指数当日涨跌”和“成员等权当日涨跌”分别注明；指数涨跌从同源日线计算，不互相替换。抗跌作为附加事实：全市场下跌时板块跌得较少，不自动称板块上涨。

新反转条件是待确认的初始研究规则，不是已验证策略。仅用已收集历史数据；交易日缺口或定义冲突时该项未知。一个板块可以有多条证据，列表按主要类型展示，统计去重。

机会排序采用可解释的条件满足情况和原排名作稳定顺序，不新增隐藏加权分。不强制每天输出固定数量；没有合格机会时给空态和待观察条件。

## 6. 数据流程与候选选择

原采集门槛通过 → 先取得原31行业历史 → 计算原行业规则与新机会诊断 → 选研究板块 → 从已取得逐股行情选最多6只股票 → 沿用原渠道深查这些股票 → 合并原个股规则 → 一次重点AI审阅 → 冻结发布 → 复核。

需要小幅拆分history.collect的行业与股票任务顺序，沿用共享预算、缓存、断点和失败机制。不在板块诊断阶段重复调用模型或逐股历史。

股票先按潜在启动/反转/趋势方向覆盖，保留衰退用于排除和风险提示；各类型轮流取所属板块流动性股票，去重后最多6只。沿用成交额≥1亿元、非ST/新股名称等原过滤。没有机会时允许候选为空，不用涨幅榜强行补齐。来源类型和淘汰原因可追溯。

为避免只看热门，AI最多8板块采用各类型轮流取证据较完整对象后，再按原规则重点补齐；不调用8次模型。股票仍最多6只。概念当日线索作为相关证据，不在首版另占深查名额。

## 7. AI任务与输出

沿用deepseek_analysis的配置Key、请求缓存与验证，升级实际prompts/decision_research.txt。普通浏览不调用AI。历史再解读继续绑定原正式报告并保留生成时点。

新增必须完成的任务：

1. 解释当前总分支持哪类研究机会，区分趋势偏弱、反转观察迹象、确认程度，不仅复述五个分数。
2. 每条机会先列输入事实，再给主要推论和至少一个合理替代解释。
3. 比较下一交易日启动、继续盘整、转弱三个情景，选“当前证据偏向/无法区分”，不凭空给概率。
4. 写出可由程序核验的确认条件和失效条件；自由文字补充与可计算条件分开。
5. 个股说明所属机会类型、为什么入选、参与障碍、最大风险；不能编造吸筹意图、机构身份、暗盘资金、目标价和低估程度。

新字段加入market.opportunity_bias及sector.hypothesis/alternative/scenarios/confirmation_checks/invalidation_checks/source_ids；程序提供指标、运算符和允许范围，AI只能引用已有condition_id，不能创建任意可执行规则。

schema_version升级，兼容读取旧decision-ui-v1。旧报告不重新套新规则，也不批量付费重解读。

## 8. 页面整合

- 今日判断：市场图示与支持度、趋势/反转条件、AI短结论；下面紧凑“今日重点机会”，默认少量方向，显示类型、已确认/待确认、触发事实、明日看点、风险、候选数。
- 板块机会：增加潜在启动/反转观察/趋势跟随/衰退风险筛选；原强弱全景与表格保留。详情按事实→推论→替代解释→确认/失效→相关个股→证据组织。
- 个股研究：显示候选来自哪条机会，价格和风险保持直接可见；加入自选后继续跟踪同一条研究逻辑。
- 我的自选：显示所属机会是否仍成立、已满足/消失的条件、最近判断变化；无法核验的日内触发不假装已发生。
- 复盘历史：原判断、后续事实、条件成立/未成立/证据不足并排，保留次日/3日/5日结果和原基准定义。
- 证据栏：复用现有入口和可访问交互，新机会证据有指标定义、数据日期和来源；事实、程序规则、AI推论分别标识。

## 9. 复盘与改进边界

原predictions.py的命中定义、交易模拟、费用和历史研究不变。新增机会条件复核只标是否确认、何时失效、缺少什么；不将AI自由文字算成功，不把线索数量或条件成立率当交易胜率。

复用第1/3/5交易日，到期但历史不完整显示不可核验，未到期显示等待。记录预测过早、确认未出现、短暂反弹、数据不足等原因。每日复盘保留失败案例；AI可总结重复错误，但不每日自动改权重或提示词。至少20个真实前瞻交易日后再初步评估，改进另存版本，不回写昨天判断。

## 10. 验收与确认范围

按顺序连续实施：独立诊断与规则测试 → 候选流程 → AI任务与真实输出核对 → 五页整合 → 浏览器走查与截图 → 回归与最终交付，中间不逐阶段审批。

验收包括：弱环境仍可显示反转观察且不升级原买入标签；没有估值和历史情绪时保持未知；非涨幅前5行业可产生候选；零机会不强推；原资金与概念发布门槛不变；新旧规则/AI版本比较不混用；原判断不被后续解读覆盖；缺失不填0；模型失败保留有效报告；1440/1024主路径顺畅，768/375无整页溢出。

需用户一次确认的实质变更：增加独立反转观察规则与机会诊断、调整候选选择及任务先后、升级AI输出和条件复核。采集128/128、概念175/175、零成员冲突、数据完整性、正式发布与旧报告保护保持原基线。估值数据源、逐股连续资金、所谓暗盘、额外回测、自动调参均不在本次推荐范围。


## 实施时的条件对齐

上涨机会进一步确认采用五项同时满足：行业指数当日上涨、收盘高于MA5、收盘高于MA20、成员等权相对全市场为正、上涨成员至少55%。UI勾选只描述本日状态，后续第1/3/5交易日重新核验。AI不能遗漏条件或把比较基准替换为沪深300。

失效参考固定在信号日：原收盘已在MA20上方时用信号日MA20，原本低于MA20时用信号日收盘。后者避免反转线索因尚未站上MA20而生成即失效；相对全市场转负仍独立触发重审。参考是行业指数点位，不是个股买入价。

现有2026-09-30报告通过绑定原发布指纹的旁路补充展示机会，原分数、名单、预测与报告没有覆盖。新的机会选股仅用于后续更新。历史概念严格读取原报告保存的成员版本，不随新快照变化。

衰退风险复核沿用原转弱定义：近5日上涨后，相对为负或上涨成员不足40%。相对转正且上涨成员至少55%表示风险缓解，不套用上涨确认条件，也不把反弹算作衰退成立。曾确认后遇到后续缺口仍保留原确认日期，但当期状态显示证据不足。
