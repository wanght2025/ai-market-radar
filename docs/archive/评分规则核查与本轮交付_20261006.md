# 更新方式、进度与评分规则核查

本轮对应用户确认的实施方案。日期为用户所在时区2026-10-06；产品内行情、资讯及更新时间明确使用北京时间。交付为本地可评审版本，不是投资规则效果已验证的发布版。

## 已实施

- 更新入口打开选择面板：当前研究、补齐所选交易日、指定日期复盘。面板显示行情范围、资讯截止时间、建议更新时间及模型计费说明。
- 当前研究自动按已核验交易日历选择最近收盘日；已有正式行情时补充证据并研究，不重新全量采集同一日行情。新交易日仍走原行情完整性验收。
- 历史补查补充公开资料；指定日期复盘复用已保存的同期证据。两者使用当日23:59北京时间的信息上限，历史观察文件与当前观察文件分开，结果保存到ai-review-historical.json。在复盘页阅读，不改写原预测、不计当时前瞻成绩。
- 四步进度条显示已完成步骤、当前阶段及已用时间。百分比由完成步骤决定，不推测网络或模型剩余时间；失败不填满。按钮防重复提交。
- 在启动更新前固定完整阅读快照；更新过程中重新打开页面，继续阅读同一份结果。单次失败不替换上次合格AI记录。
- 资料采集时间、资讯已知时间、迟到主营资料的具体采集日期，不再单独使研究失效。真正改变的金额、发布日期、正文、公告状态仍触发重新核验。
- 按资金、海外行情、政策资讯、公司公告、成交活跃度标出变化。新增普通资讯不会删除仍匹配原官方正文的政策补评。
- 新报告AI失败时，上一份合格研究可以在行情、候选和行业事实一致的情况下保留，随后再逐项核对证据。如果基准改变，只展示历史意见。
- 首页展示指数趋势、上涨比例、成交额，政策与事件作为解释和风险层。旧总分、权重和门槛保留在折叠区，补评不升级原个股参与条件。
- 技术性“供应商”改为实际数据来源或“东方财富行业分类／资金估算”。市场情绪改称市场参与度。
- 盘前自动检查窗口提前至08:30；建议电脑08:25前就绪。没有开启自动运行开关。

## 五维评分逐项核查

| 规则 | 原条件 | 核查结论与处理 |
|---|---|---|
| 技术，权重30 | 上证、深证、沪深300收盘高于MA20的比例 | 仅0/33.33/66.67/100四档且指数覆盖重叠；保留原规则作诊断，首页显示实际0/3等事实。历史重复日期不再计作足够样本。尚不能证明均线具有预测效力。 |
| 资金，权重25 | 东方财富分类净额为正数量÷完整分类数量 | 忽略金额及持续性，受分类拆分影响；不再称普遍资金支持，独立展示金额及已取得的连续序列。不跨分类映射申万行业，不归因机构身份。历史序列不完整时不填0。 |
| 政策，权重15 | 有官方正文与同期日期的AI主观0—100分 | 有来源不等于数值已校准。仍存作旧规则补评；首页说明政策对象、影响与边界。区分来源失败与有限范围未发现事件，不补中性50。 |
| 国际，权重10 | 标普500高于MA20给75，否则25 | 只是单一代理；首页改为分别列示各资产已结束日线及日期。原评分明确过滤目标日之后的数据、检查重复日期。各市场收盘时间另由观察层校验。 |
| 参与度，权重20 | 上涨比例×0.7＋(50＋等权涨跌百分数×10)×0.3，限制0—100 | 系数、截断及与技术的重复计量未经检验；更名后保留诊断，首页使用原始上涨比例与等权涨跌。大涨≥5%不称涨停，大跌≤−5%不称跌停。 |
| 总分与65门槛 | 五项齐备后按30/25/15/10/20加权 | 没有依据支持这些权重与65门槛的投资效果；不另造一套权重。总分不再作为首页买入结论，也不把缺少政策评分说成行情不可用。 |

## 板块、候选与个股条件

| 条件 | 核查与处理 |
|---|---|
| 原回避规则：技术<34且参与度<40 | 修复政策补评达到65后覆盖回避的漏洞。风险条件优先；测试覆盖技术33.33、参与度39、其他高分使总分65.30的反例。 |
| 相对表现 | 原字段计算行业成员等权相对全市场等权；生成解释同步改用这个基准，不再误写跑赢沪深300。历史原报告仍保留当时文案。 |
| 潜在启动：广度≥50、近5日−2%至3%、距MA20≤2.5%、成交额≥前5日均额1.2倍 | 这是启发式筛选，不是已验证“即将启动”。保留原数值并列入后续效果检验，不冒充收益概率。行业日线仍要求与基准21交易日序列一致。 |
| 反转观察 | 近5日下跌用于识别信号；确认改为当日上涨、高于MA5、相对为正、广度≥55。不再强制先高于MA20，也不要求后续确认日仍保持近5日下跌。新增诊断版本opportunity-v1.1；冻结的v1条件原样核验。 |
| 趋势跟随 | 保留趋势、广度和相对强度条件；同样待检验，不能套作所有市场环境的统一策略。 |
| 衰退风险 | 保留近5日上涨后相对为负或广度<40及恢复条件；相对为正不等于绝对上涨。 |
| 固定失效参考 | 保留信号日参考用于复盘，明确为行业指数点位，不是个股买入价；动态均线与固定信号参考不混称。 |
| 候选成交额≥1亿元、行业内按成交额筛选、研究数量上限 | 存在规模与流动性偏差；只作为有限研究范围，候选不是完整机会集，更不是买入排名。未取得历史同口径完整样本前不改成另一套任意阈值。 |
| 个股门槛 | 原完整市场门槛、板块确认、个股MA20、同期主营、标题风险及公告获取分别保留。AI政策补评不替代程序资格；缺少公告正文的风险限制仍显示。 |
| 主营与公告时点 | 晚取得的主营资料不能证明历史当时已知。采集日期变化不改变这个资格；主营事实、公告正文与来源状态变化会改变证据。公告空样本不等于无风险，标题样本不等于全文核验。 |
