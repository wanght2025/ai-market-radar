# 市场雷达：AI 的输入、任务与输出

阅读路径是市场图示 → AI短结论与机会偏向 → 板块推论 → 明确个股结论与参与条件 → 证据与后续复核。程序提供数字和条件，AI解释它们意味着什么；未知信息保持未知。

## 实际提示词

程序直接读取 `prompts/decision_research.txt`，当前输出为 `decision-ui-v2`，前端继续兼容旧v1。首页“完整市场判断、来源与AI任务”可以打开实际提示词、条件校对任务和定点事实校对任务。

## 输入与范围

| 输入 | 研究任务与边界 |
|---|---|
| 行情日期、生成日期、原发布指纹 | 区分真实前瞻与历史再解读 |
| 原五维评分、指数MA20、市场广度、强涨/强跌 | 解释参与支持，不把总分当上涨概率 |
| 供应商资金正向比例、融资、ETF、有限政策/国际样本 | 只在市场层面独立解释，不硬映射申万行业 |
| 机会类型、行业量价/广度、原规则状态 | 解释潜在启动、反转观察、趋势跟随与衰退风险 |
| 固定确认/失效条件与允许的条件ID | 写可复核的情景，不自创可执行规则 |
| 最多6只候选股的行情、归属、风险与参与障碍 | 检查同期主营、既有趋势/风险与参与前提；不捏造执行价格 |
| 有日期及来源的有限事件样本、证据ID | 支持引用与替代解释，不当成全面事件覆盖 |

31个申万行业由程序全量扫描；AI按机会类型覆盖最多8个行业、最多6只股票。175概念提供当日成员线索，不另占股票深查名额。供应商128行业资金分类独立；这些覆盖数不能相加称为独立预测板块数量。

## AI必须完成的事情

1. **解释环境与机会的关系。** 总分低可以同时出现反转观察迹象；解释趋势跟随的缺口与反转尚缺的证据，保持原大盘参与标签。没有估值和连续情绪历史，不称低估、极端恐慌或底部确认。
2. **提出有差异的板块推论。** 每个板块给主要推论、合理替代解释、启动/盘整/转弱三种条件性情景和当前证据偏向；不编造概率、暗盘、国家队身份或吸筹意图。
3. **明确下一交易日及3–5日复核。** 所有确认和失效ID必须完整匹配程序条件。相对表现的基准为行业成员等权相对全市场，不替换为沪深300。上涨机会失效使用固定信号日参考，不能偷偷改成新的均线阈值；衰退风险单独检查转弱持续与风险缓解，不把反弹算作衰退预测成立。
4. **说明股票为什么关注、为什么尚不能参与。** 行业归属不证明主营受益，公告有限样本不证明无风险，MA5/MA20是观察参考而非买入价。
5. **为复盘留下可以检查的条件。** 复核窗口不是上涨持续天数；没有合格历史样本时拒绝估计时长。自由解释不作为交易成功率。

v2新增 `market.opportunity_bias`、板块的 `hypothesis/alternative/scenarios/scenario_bias/confirmation_checks/invalidation_checks`；保留市场短标题、确认/风险、板块次日/近期解读、个股前提/风险及证据引用。

## 调用、校验与保存

日常更新沿用原模型调用位置。浏览只读取结果，不调用模型。机会任务的单次输出上限至少16384 token，以容纳当前配置的思考与结构化回答；全局模型配置未修改。输入限制仍是一次重点研究，最多8板块和6股票，不循环调用8次。

显式历史再解读绑定原正式发布指纹，保存为 `data/daily/日期/ai-review.json`。独立规则补充保存为 `opportunity-snapshot.json`，也校验发布指纹。AI失败单独记录，不替换有效解读；原报告、原预测、原评分和历史名单继续保留。再解读不进入当时前瞻表现。

程序验证日期、代码、遗漏、重复、证据ID、态度、必要字段和全部可执行条件；拒绝未知或遗漏条件和未经映射的行业资金归因。结构校验不能证明投资效果，仍需语义核对。经定点校对的结果保留主调用生成时间，附加校对时间与任务来源；当前有效结果通过兼容性核对后可直接复用。
