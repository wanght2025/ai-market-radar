# 市场雷达改版交付记录

本轮针对使用路径、重复更新入口、运行状态与报告、环境评分、海外数据与事件，以及处理数量占据首页六个问题进行了修改。最后一轮真实研究已通过业务校验，且与页面当前证据匹配。

## 日常使用

1. 打开研究首页，查看行情日期、资讯时间、市场状态和主要风险。
2. 查看「值得继续研究的方向」，点击板块核对依据、确认条件和失效条件。
3. 在「我的自选」检查股票变化；修改自选后，下一次更新会取得名单行情。
4. 点击右上角「更新研究」，自动检查行情、更新资讯并生成研究。过程中可以继续阅读已有结果。
5. 日期选择用于阅读历史行情研究；右上角更新默认取得最近已完成的行情。指定历史日期和单独重试操作在「数据与设置 → 高级更新与诊断」中。

新 AI 请求按配置预算计费，匹配的合格缓存可以复用。失败保留已有研究，不自动反复调用模型。历史行情与后来资讯分别标明日期。

## 本轮修改

| 原问题 | 已交付行为 |
|---|---|
| 不知道怎么使用 | 首页提供三步阅读路径，先展示判断、图表、依据和风险，再进入板块与自选。 |
| 更新入口过多 | 日常使用一个全局更新按钮；局部更新进入折叠的高级诊断。更新中展示阶段、防止重复启动、保留可读结果。 |
| 运行状态、报告用途混乱 | 采集状态成为诊断页，明确行情通过不代表研究已就绪。诊断与存档阅读界面统一浅色；存档提供返回首页入口。冻结记录没有改写。 |
| 环境总分缺失导致首页失去用途 | 缺分仍显示可用分项与市场事实。有来源且匹配当前证据的政策补评可展示补充环境分；旧证据补评不能用于当前展示。补充环境分不会自动改变原日判断或个股参与资格。 |
| 国际行情与事件混在一起、采集不充分 | 分成海外市场变化和重要事件与影响；资讯最多取得三页，去重，分页失败保留已取得样本。送入 AI 的样本保留政策、国际和产业主题。缺失主题与来源失败不解释成没有事件。 |
| 处理数量代替信息 | 移除首页线索、审阅数量和覆盖率指标排，展示重点方向、资金比较图、行情图及研究结论。诊断指标留在设置与证据中。 |

## 数据与研究修复

- 公告采集批次不再读取不存在的日期字段；真实更新中六个候选公告批次均恢复成功。成功取得批次不等于公告风险全文已核验。
- 补充研究与当前阅读使用当前证据，避免被原存档的截止时间挡住；原始研究窗口仍保存在存档中。
- 政策评分引用只能来自本次可见官方正文与同期日期；禁止沿用旧请求的事件编号。
- 对未映射资金和未提供成分权重的文字保持严格校验；真实失败被保留，没有通过降低标准变成成功。
- 财政部收益率接口不可用时使用 FRED 的 DGS10 日度序列，检查列名、日期、有效值和截止时间，拒绝其他期限及未来日期。来源：[FRED DGS10](https://fred.stlouisfed.org/series/DGS10)。

## 仍需保留的限制

- 美元／离岸人民币原接口连接失败；备用接口仅返回当前报价，未返回可核验的历史日线，因此没有用它填补历史数据。
- FRED 收益率最新可取得日期为 2026-10-02，不能写成 10 月 5 日数据。
- 资讯是有来源和时间的有限样本，并未证明国际事件完整覆盖。该版不能以「全球资讯全部取得」宣传。
- 规则门槛与补充环境分尚未完成前瞻效果校准；界面可用不代表评分已证明有预测效力。

本轮交付为本地可评审版本，未发布到外部服务。
