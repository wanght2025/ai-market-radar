# 首页判断修订记录

版本：1.0.0-rc.5。对象：2026-09-30 收盘快照。

此前首页把“分化”“先核对”和数据缺口放在主位置，用户仍需自行拼接指标。本次把原规则的行动、依据、候选资格和改变判断的条件放到首屏。

## 已实施

- 首屏直接显示“暂不新增参与，先观察”，并给出三个核心指数均未站上20日均线、上涨股票占比46.1%的依据。
- 显示6只候选、0只通过参与核验，提供个股详情入口；板块关注不能自动升级为个股可参与。
- 说明当前分项即使补满缺项，总分也至多42.23，低于原65分门槛；需要现有行情条件改善，而非仅等待AI生成。
- 首页展示最多三个重点方向，逐项显示取舍理由、下一步观察情景、原条件失效参考和相关个股入口。明确区分AI情景与原规则条件。
- 将评分、研究时点、数据缺口及详细市场事实放入可展开区域；处理结束后不再展示误导性的“已完成0/4”。
- 取消当前配置的每日AI请求次数上限。保留每日262,144 tokens预算和原单次输出上限；预算不足仍会停止新请求。

## 真实AI与事实核对

本次实际新增1次DeepSeek请求：输入17,739、输出13,904，合计31,643 tokens。当天累计6次请求、187,104 tokens，检查时剩余75,040 tokens。

初次响应包含一条不存在于本次输入的事件编号。核对政策原文还发现“存量房不覆盖”与正文明确包括二手房相冲突。本次只剔除这两条事件推论，保留其他通过现有校验的内容；页面显示未采用数量及具体原因。

原始模型文本保留在 artifacts/decision-first-20261006/ai-response-original.json。修复后复用同一响应，要求输入指纹完全一致，再执行结构、引用、均线关键事实与参与资格校验，没有第二次模型调用。新增政策冲突检查只覆盖已发现的这类错误，不代表自动核实全部政策解释或预测。

现有评分权重、65分门槛和参与资格没有改动，规则有效性仍待前瞻验证。AI补充意见与原规则并列展示。
