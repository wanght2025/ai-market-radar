# 市场雷达：Windows 本地研究工具

当前版本 **1.0.0-rc.6**，用于小范围试用验收，尚未正式发布。提供五项环境评分、入场状态仪表、AI研判、板块和个股研究、自选及已保存预测的复核。预测与投资效果尚未验证。

2026-10-10发布前审查修复了失败退出码、损坏预算/缓存、安装目录越界、原始响应保留和日志读取问题。正式发布结论及未验证项见[验收规则](VALIDATION.md)。

集中收尾补齐备用来源错误日志、请求会话关闭和写入失败回退；29个依赖版本不变，安装时强制核对官方发行文件SHA256。源码可公开试用，当前仍为候选版，实际Windows125%/150%缩放验收尚未完成。

## 首次使用

1. 安装Python 3.12并加入PATH，将发行ZIP解压至可写目录。
2. 双击 `run.bat`；首次创建独立`.venv`并联网安装锁定依赖。
3. 打开 `http://127.0.0.1:8768`，进入“数据与设置”。
4. 填写DeepSeek API Key，勾选“启用AI研究”，点击“保存AI配置”。
5. 点击“测试连接”。成功后使用右上角“更新研究”；失败原因在同一区域显示。

留空Key保存会保留已存Key，取消启用不会删除Key。Key保存于本机`.env`，不在状态接口回显；系统环境变量`DEEPSEEK_API_KEY`优先于文件。无Key或关闭AI仍可启动并阅读已有存档。

仅浏览、点击评分和展开证据不会调用模型。连接测试只读取模型列表。首次遇到新政策正文会先做短政策补评，再生成完整研究，均使用同一个已配置模型；相同输入和参数复用校验通过的缓存。请求次数不限，保留每日262144 tokens预算及失败不自动重试的保护，实际用量在设置中显示。

## 评分如何传递

原始评分保存在`decision.original_market`，政策补评保存在`decision.policy_assessment`。按原权重合成后，**`decision.market.score`是唯一最终有效总分**。参与判断、AI输入、最终报告与UI共用该字段。同期证据不足时总分为空，不用0或中性分填补。历史报告和原预测保留。

权重仍为技术30%、资金25%、政策15%、海外10%、情绪20%。市场门槛65分、五档展示分界80分及候选股条件保持原实现；分档不表示建议仓位或成功率。政策项是有来源的有限样本主观评价。

## 数据与预测边界

行情使用已完成的A股收盘日期，资讯显示各自时点。供应商行业资金不直接映射其他行业分类；ETF份额不等于现金流入。缺失渠道不填零，原因和影响在页面中说明。有限公告样本不表示已完成全部风险排查。

AI输出经过结构、引用、均线、已知数值与内容一致性检查，错误输出保留原文并暂停采用。检查通过不代表所有推断正确。未来1日、3—5日预测是条件性情景，真实前瞻样本仍需逐日积累。

已知限制：免费上游可能断开；定时日历仅核验2026年；Windows实际125%/150%缩放尚待验证。失败任务返回非零退出码；无AI配置或预算耗尽时可完成资料处理，页面明确显示未生成新AI。

## 自动运行

设置页可开启Windows定时任务，每5分钟检查。北京时间交易日18:00盘后、08:30开始盘前检查，09:15前成功完成才可采用。建议08:25前开机、联网并保持登录。2026年以外年历未知时暂停相应调度。
